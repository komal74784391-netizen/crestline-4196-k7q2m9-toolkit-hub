# Signals & Sensor Fusion

Companion toolkit for **ASE-2040 - Signals & Sensor Fusion** (Applied Systems Engineering programme, Crestline Institute of Applied Technology).

## Repository Status

Released. The toolkit is public and maintained by the Applied Systems Engineering teaching group.

## Layout

- `src/` - reference implementations for the lab sessions
- `data/` - small sample datasets
- `experiments/` - configuration used to reproduce the published results
- `notebooks/` - walkthrough notebooks
- `results/` - summary tables
- `tests/` - smoke tests

## Citation

Crestline Institute of Applied Technology. *Signals & Sensor Fusion Companion Toolkit*. ASE Programme Technical Report ASE-2040, 2026.
