# Digital Twin Modelling

Companion toolkit for **ASE-2480 - Digital Twin Modelling** (Applied Systems Engineering programme, Crestline Institute of Applied Technology).

## Repository Status

To be released. This repository will contain the reference implementation and the experiment notebooks; the toolkit is still in final review and is not yet public.

## Layout

- `src/` - reference implementations for the lab sessions
- `data/` - small sample datasets
- `experiments/` - configuration used to reproduce the published results
- `notebooks/` - walkthrough notebooks
- `results/` - summary tables
- `tests/` - smoke tests

## Citation

Crestline Institute of Applied Technology. *Digital Twin Modelling Companion Toolkit*. ASE Programme Technical Report ASE-2480, 2026.
