# Applied Machine Vision

Companion toolkit for **ASE-2410 - Applied Machine Vision** (Applied Systems Engineering programme, Crestline Institute of Applied Technology).

## Repository Status

Released. The toolkit is public and maintained by the Applied Systems Engineering teaching group.

## Layout

- `src/` - reference implementations for the lab sessions
- `data/` - small sample datasets
- `experiments/` - configuration used to reproduce the published results
- `notebooks/` - walkthrough notebooks
- `results/` - summary tables
- `tests/` - smoke tests

## Citation

Crestline Institute of Applied Technology. *Applied Machine Vision Companion Toolkit*. ASE Programme Technical Report ASE-2410, 2026.
